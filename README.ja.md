# 医療向けCLIPモデルによる脳腫瘍MRIのZero-shot / Few-shot分類

[English](README.md) | **日本語**

このリポジトリは、事前学習済みの医療向け視覚言語モデル(**BiomedCLIP**、**PubMedCLIP**)が、**学習データなし(Zero-shot)**、および**クラスあたりごく少数のラベル付き画像(Few-shot)**で、脳腫瘍MRI画像をどこまで分類できるかを調べた実験をまとめたものです。

もともとはCLIP系の視覚言語モデルに関する演習課題でしたが、次の問いに答えるための対照実験(アブレーション)へと発展させました。

> **CLIP系モデルが下流の医療画像タスクで高い精度を出すとき、その要因は (a) 凍結された事前学習済み特徴の質そのものなのか、(b) その上で行う追加学習(線形プローブ、部分的なファインチューニングなど)なのか?**

## 結論(要約)

すべての実験を通じて、**下流タスクの精度の大部分は、事前学習済みエンコーダの質によって決まっていました**。凍結したバックボーンの上に追加学習(線形分類器の学習や、ViTの数層の凍結解除)を行っても、精度の向上はわずかで、統計的に有意とは言えないことが多く、ラベル付きサンプルが極端に少ない場合はむしろ精度が下がることもありました。

| 設定 | BiomedCLIP | PubMedCLIP |
|---|---|---|
| Zero-shot(最良のプロンプト) | 63.87% | 40.74% |
| Few-shot、16-shot、線形プローブ | 82.41% | 67.56% |
| Few-shot、16-shot、**学習なし**(クラス平均プロトタイプ) | 84.74% | — |

「学習なしで特徴を平均するだけ」の場合(84.74%)と、「線形層を20エポック学習した」場合(別の実行で86.90%)の差は約2ポイントです。一方、同じ線形プローブ設定の2回の別実行の間でも、それ以上の差(82.41% と 86.90%)が出ています。そのため、今回の実験ではこの2つの方法を区別できず、**事前学習済みバックボーンが精度の大部分を担っている**という見方と整合します。(ただし[制限事項](#制限事項)にあるとおり、実行間のばらつきの一部は、乱数シードだけでなく、モデルの状態共有の問題に由来する可能性があります。)

## 比較したモデル

| モデル | 画像バックボーン | テキストバックボーン | 事前学習データ |
|---|---|---|---|
| [BiomedCLIP](https://huggingface.co/microsoft/BiomedCLIP-PubMedBERT_256-vit_base_patch16_224) | ViT-B/16 | PubMedBERT | PMC-15M(約1,500万組の生物医学の画像・テキストペア) |
| [PubMedCLIP](https://huggingface.co/flaviagiammarino/pubmed-clip-vit-base-patch32) | ViT-B/32 | CLIPテキストエンコーダ(ファインチューニング済み) | ROCO(約8万組の放射線画像・キャプションペア) |

どちらもCLIP型の二塔(dual-encoder)モデルです。画像エンコーダとテキストエンコーダを対照学習で同時に学習し、対応する画像とテキストが共通の埋め込み空間で近くに配置されるようにします。ViT、BERT、CLIPの対照事前学習の仕組みについては [`docs/background.md`](docs/background.md)(英語)で基礎から説明しています。

## データセット

BTMRI(脳腫瘍MRI)— 4クラス、クラスごとに1フォルダ:`glioma_tumor`、`meningioma_tumor`、`normal_brain`、`pituitary_tumor`。

このデータセットは、元の演習課題で `BTMRI.zip` として配布されたもので、Few-shot実験で使う固定のtrain / val / test分割を定義する `split_BTMRI.json` が付属しています。Kaggleにも類似の公開脳腫瘍MRIデータセットがありますが、フォルダ名と分割が異なります。データを再配布する場合は、必ず出典とライセンスを確認してください。

元のMRI画像は**このリポジトリには含まれていません**(ライセンス・容量の理由)。各自でダウンロードし、notebook内の `data_dir` をご自身のコピーの場所に変更してください。

## 実験

### 1. Zero-shot分類
学習は一切行いません。クラス名をテキストプロンプトに埋め込み(3種類のテンプレートを比較)、テキストエンコーダで符号化して、画像の埋め込みとのコサイン類似度を計算します。予測は最も類似度の高いクラスのプロンプトです。

**結果:** プロンプトの書き方で精度が変わりました。BiomedCLIPでは、汎用的な「`a photo of X`」より「`X presented in image`」の方が約6ポイント高く、これはモデルが事前学習で見た生物医学文献の文体に近いためと考えられます。

### 2. Few-shot線形プローブ
画像エンコーダは**完全に凍結**し、新しく追加した `nn.Linear(512, num_classes)` の分類ヘッドだけを、クラスあたり1 / 2 / 4 / 8 / 16枚で学習します。

**結果:** BiomedCLIPはショット数の増加とともに精度が着実に上がりました(67% → 82%)。PubMedCLIPはほとんど伸びませんでした(57% → 67%、単調ではない)。これは、事前学習コーパスがはるかに小さく多様性も低いことと一致します。

### 3. 学習なしのベースライン(クラス平均プロトタイプ)
分類器を学習する代わりに、各クラスをFew-shot画像の埋め込みの平均で表し、テスト画像を最も近いプロトタイプ(コサイン類似度)に分類します。Zero-shotと同じ「比べて一番近いものを選ぶ」仕組みですが、基準となるベクトルがテキストプロンプトではなく、平均した画像特徴である点が違います。

**結果:** この学習不要のベースライン(16-shotで84.74%)は、学習済みの線形プローブにほぼ並びました。精度の大部分は、線形層の20エポックの学習ではなく、凍結されたバックボーンがもともとよく分離した特徴空間を作っていることに由来すると考えられます。

### 4. 画像バックボーンの部分的な凍結解除
分類ヘッドは残したまま、ViTの最後の *N* 個のTransformerブロックも凍結解除して一緒に学習します。

**結果(暫定 — 1回の実行のみ、要再検証):** ショット数が非常に少ない場合(1〜2-shot)は、凍結解除によって精度が下がりました(ViTの数ブロックだけで数百万の学習可能パラメータがあるため、過学習の可能性があります)。8-shot前後からようやく効果が出始めました。その後、16-shot固定で凍結解除の深さ(0/1/2/4層)を変えて調べましたが、きれいな単調な傾向は**見られませんでした**。この部分は、確定的な結論を出す前に、複数の乱数シードでの繰り返しが必要です(「制限事項」を参照)。

## 制限事項

- Few-shotの数値の多くは**単一の乱数シード**によるものです。特に第4節(部分的な凍結解除)では、16-shotで2回の別実行が矛盾する傾向を示しました。また、「学習なし」と「学習済み線形プローブ」の差(2〜4ポイント)は、観測された実行間の差と同程度です。**複数シードでの繰り返し(設定ごとに3〜5シード、平均±標準偏差)は計画していますが、まだ完了していません**。単一実行の数値は目安として扱い、結論とはしないでください。
- **モデルの状態共有の問題(実験後に判明)。** `LinearProbe(model, ...)` はグローバルな `model` のコピーではなく参照を保持します。ViTブロックを凍結解除した実行では、その重みがその場で書き換えられ、同じセッション内の後続の実行は、元の事前学習済みの重みではなく、書き換えられた重みから始まっていました。バックボーンを完全に凍結した実行(最初の1〜16-shotの線形プローブの曲線と、PubMedCLIPの実行)は影響を受けません。一方、凍結解除の結果(第4節)、および同じセッションでその後に実行していた場合の `unfreeze_last_n=0` のベースラインとプロトタイプの結果は、毎回事前学習済みの重みを復元したうえで再実行する必要があります。それまでは、上に挙げた実行間の差を、乱数シードだけのせいにしないでください。
- バッチサイズはFew-shotの訓練セット全体に設定されています(`train_batch_size = shot_num * num_classes`)。そのため、ショット数にかかわらず、1エポックあたりの勾配更新は必ず1回です(20エポックで合計20回)。したがって「ショット数が多いほど精度が高い」という傾向は、更新回数の違いによって交絡していません。ただし、バッチサイズを切り離して固定する明示的なアブレーションはまだ行っていません(`docs/background.md` の第6節を参照)。

## 今後の予定

- **LoRA**(パラメータ効率の良いファインチューニング):「線形プローブのみ」(学習パラメータが少なすぎる)と「ブロックごと凍結解除」(パラメータが多すぎて、ごく少ないショット数では過学習する)の中間の方法として試します。
- **知識蒸留**:BiomedCLIPの出力分布をソフトターゲットとして使い、PubMedCLIPの事前学習コーパスの小ささをある程度補えるかを調べます。
- 「制限事項」に書いたとおり、すべてのFew-shot実験を複数の乱数シードで繰り返し、平均±標準偏差を報告します。
